# ThreatLens

**ThreatLens - See the Threat. Understand the Risk. Make Informed Security Decisions.**

ThreatLens is a multi-source Cyber Threat Intelligence and Malware Analysis platform for investigating URLs, IP addresses, domains, and file hashes.

## Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS, React Router, Axios, TanStack Query, Recharts, Lucide React, and Zod
- Backend: Python 3.12+, FastAPI, Pydantic v2, SQLAlchemy 2.x, Celery, Redis, and PostgreSQL
- Quality: pytest, Vitest, React Testing Library, Ruff, Black, mypy, ESLint, and Prettier

## Development status

The project is being implemented in the gated sequence in the build prompt. Step 1 establishes the repository and tooling skeleton. Docker-based verification will begin after Docker Engine and Docker Compose are installed.

## Local setup

Prerequisites:

- Python 3.12+
- Node.js 20 LTS+
- npm
- Docker Engine and Docker Compose

The complete setup and environment-variable reference will be documented as subsequent steps are completed.
